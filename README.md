# Student-Study-Planner

##Project Description 
Student Study Planner is a begineer-friendly Python project that helps students manage their study tasks.

##Features
-Add study tasks
-View all tasks
-Mark tasks as completed
-Delete tasks
-Exit the program

##Technologies Used
-Python

## How to Run
1.Download the python file.
2.Open it in VS Code.
3.Run the program.
4.Select an option from the menu.
